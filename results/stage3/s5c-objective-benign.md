## Two defects found before launch, and fixed (tested)

1. **`--no-insiders` in the prepared assignment would have produced zero scenario sessions.** `campaign_schedule_for` (`mole/generator/run.py`) gives every coalition account an explicit empty schedule when `attack_session_rate <= 0`, in every planning mode (its docstring; `tests/test_coalitions.py::test_runner_no_insiders_with_coalitions_unchanged`). Proved at $0 by calling the planner on the placeholder maps: with the default rate each account gets `[('2026-04-06', 'act')]`; with rate 0 each gets `[]` (tested, this session). The flag was removed from `generation.extra_flags` (reason recorded inline in the file). The Stage 2b branches were launched without it. The rules-mode rehearsal could not have caught this: rules mode ignores insiders and computes role days on its own path (the manifest check passed with the flag present).
2. **The D5 post-attack path stayed on under the benign carrier** (branch review, spec finding c2): after its scenario session, a scenario account's later sessions got the release-gate standing note prepended and gate tasks filtered from the draw, so the same-run honest sessions would not have been honest sessions. Fixed in `mole/generator/agentic_member.py` (`post_attack` is false under the benign carrier; the legacy carrier is unchanged) with `test_benign_carrier_turns_the_d5_post_attack_path_off`. Also added, for L1 rule 2: `manifest["objective_carrier"]` and `manifest["elicit_share"]` with `test_manifest_records_the_carrier_flags`.

## What is recorded, and the reading rule (written before launch)

Script: `work/checks/stage3_s5c_metadata.py` (copy under `scripts/stage3/`), outputs `work/stage3/s5c-metadata.{json,md}`.

1. **The four metadata features per session** (session length = turn count; capped = turn count at the 50-turn cap; events per session = audit rows with the session's task id; first-action time = simulated minutes since midnight of the first exit-code-0 event) for the 3 scenario sessions and the 3 same-run honest sessions, beside three honest references: the same-run honest sessions (confound-free, n = 3), the prefix's 224 honest sessions (substrate (ii) in-process: a stated confound), and, if the S0 smoke's corpus exists by then, its 20 honest lab sessions (substrate (i), with GitLab: a stated confound in the other direction). Quantiles per group; each scenario session's percentile rank in each honest group; per-feature rank AUROC scenario vs each group. **Reading rule:** these are descriptive at n = 3 vs 3. The number that would worry a pilot is a scenario session outside the honest [p5, p95] on a feature where the same-run honest sessions are inside it, consistently across the three accounts; one such session is noise.
2. **Both frozen leak classifiers at account-day level, the run's three account-days (positives) against the prefix's 118 (negatives)**, exactly the brief's "against the prefix": `grouping_measure.metadata_features` + `leak_classifier`, and `stage3_leak_content.content_matrix` + `leak_classifier`, seeds as in rung 2. With three positives the frozen classifier returns the point AUROC only (no interval below five positives), and the comparison carries the substrate confound (lab vs in-process) on top of the carrier effect, so **no gate is applied** and the number is reported as plumbing evidence: the pipeline runs end to end on a carrier corpus and produces a number of the expected shape. The design's rung-3 gate (both classifiers at most 0.6, or the calibrated permutation band of rung 2's post-hoc section) is for the pilot, where positives and negatives share a substrate.
3. **Turn-cap rate** across the 6 sessions, **aborted count**, **finish reasons**, **failed-event share**, **sessions per hour** (completed sessions over the session-phase wall-clock from the timestamped log) and **cost per session** (`scripts/cost_report.py`, provider-reported, beside the key delta) for the prep report's section 9 estimate.
4. **The placeholder's effect on state:** did each scenario session write `/shared/README.md` (audit rows `owncloud.write_file` on that path with exit code 0)? Recorded as the carrier's yield at the matched budget, descriptive.
